## Overview

**tl;dr** (too long; didn't read) is an AI-powered browser extension that instantly summarizes articles, emails, and any text content using Groq/Llama 3. Available for Chrome, Firefox, and all Chromium-based browsers.

## Features

- **Sidebar Summarization** - Click the toolbar icon to open a sidebar and summarize any page instantly
- **Right-Click Context Menu** - Select text, right-click, and get a summary without leaving the page
- **Email Support** - Scan your inbox and extract actionable tasks from emails
- **Multi-Language Support** - Input in any language, output in your preferred language (15+ languages supported)
- **Customizable Tones** - Choose from 6 different summarization styles:
  - Skimmer (Brief headlines)
  - Researcher (Factual, objective)
  - Analyst (Detailed, full context)
  - Teenager (Simple, jargon-free)
  - Critique (Critical analysis)
  - Executive (Actionable strategy)
- **Customization** - Adjust font size and language preferences

## How to Use

1. **Install** the extension from your browser's store
2. **Click** the tl;dr icon in your toolbar to open the sidebar
3. **Right-click** on selected text and choose "tl;dr this"
4. **Adjust** summary tone and language in settings
